## Hard constraints (a proposal that breaks one is rejected)
1. Two profiles, in `config/profiles.md`. `personal` (the default) is $0: free/open-source tools, open-weight models, free tiers only. `company` may name a paid model API and a paid host. Switching profiles does not change 556 h / 255 tasks and does not replace the [ME] loop with a vendor agent product. A proposal that breaks the active profile is rejected.
2. 20 h/week. The core is already 556 h / 255 tasks / 30 weeks. Every proposal states its hours delta. A net addition must name what it replaces or which cut-list item it pushes out. Proposals that REMOVE work are welcome.
3. The point is learning the agentic layer. Work tagged [ME] (agent loop, tool schemas, context manager, verifier, judge rubric, eval scorer, state machine, threat model, ADRs) stays [ME]. Never propose replacing it with a library: borrow ideas, not dependencies.
4. No agent framework as a dependency before the P3 baseline (ADR-011).
5. No invented numbers. Every number needs a source link; results cells stay "—".
6. Licences: MIT/Apache/BSD = ideas and small snippets with attribution. GPL/AGPL/ELv2/unknown = ideas only.
