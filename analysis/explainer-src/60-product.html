04 Final productThe finished Argus, as a clickable prototype

Five screens in one flow: type an issue, watch the run, review the verdict and the before/after, see the PR the agent raises, then check history. Everything inside the frame is a prototype: nothing is uploaded, no model is called, and no pull request is ever created. Use the switcher to see the quota, stuck, verifier-failed and judge-disagrees cases.
