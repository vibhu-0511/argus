## What exists

- `.github/workflows/eval-gate.yml`, on every push: checkout, `astral-sh/setup-uv` (Python 3.12), `uv run pytest packages/eval/tests -q`, then `uv run --package eval python -m eval gate packages/eval/results/current.json --baseline packages/eval/results/baseline.json`. No secret, no model call, no network after the dependencies are installed (`permissions: contents: read`).
- `packages/eval/results/baseline.json`: the stored baseline, the real P3 variant A run (20/29), a copy of `packages/eval/fixtures/gate/baseline.json` (its README says which numbers are real).
- `packages/eval/results/current.json`: the results file CI gates. Today it is byte-identical to the baseline, so the gate passes. A new eval run overwrites this file in a commit; `baseline.json` changes only in a reviewed PR (ADR-017).
