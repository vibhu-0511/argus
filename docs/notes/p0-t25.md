# P0-T25 Equivalent mutant

## Induced failure

`remove-class` treated every class token as an edit site. Removing a lone class such as `className="marker"` changes the class name and leaves no class token. That class is not `flex-row` or `flex-col`, so the edit has no visual effect a computed-style check can see. The mutant scores 0.

## Signal observed

`judge_mutant(0, 0, ["computed_style"])` rejects the mutant. The reason code is `no-observable-change`.

## Fix

`removeClass` keeps a token when its text is `flex-row` or `flex-col`, or when that element still has another class token after this one is removed. A lone token that is neither of those is not an edit site, and `edit` returns null. On the operators fixture (`alpha flex-row`, `beta flex-col`) those tokens stay edit sites.
