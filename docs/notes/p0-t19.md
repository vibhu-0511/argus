# P0-T19 Stale golden patch

## Induced failure

A golden patch no longer applies cleanly. Temp task `stale-probe` has a `bug.patch` that does not apply, and a `golden.patch` whose context does not match the committed tree.

## Signal observed

`golden_all` on that task printed `fail stale-probe` and returned non-zero. `score_task` was not called. `.github/workflows/golden.yml` runs `uv run bench golden --all` and does not set `continue-on-error`, so a non-zero exit fails the job. GitHub red was not observed because there is no remote.

## Fix

Regenerated `golden.patch` against the committed tree so `git apply` succeeds. The same call printed `pass stale-probe` and returned 0.
