# P0-T20 Break it: nondeterministic animation

## Induced failure

Fixture task `anim-probe` (pytest `tmp_path` only, not under `packages/bench/tasks/`) is one route. Its stylesheet `route.css` contains a randomised transition delay:

```css
transition-delay: random;
```

## Signal observed

The scorer reads that stylesheet. While the delay line is present, successive scores are mixed 0 and 1. `flake_all` — the function `bench flake --all` calls — was invoked with that scorer, `tasks=[anim-probe]`, distinct buggy and golden paths, and a quarantine directory. It returned 1, printed `anim-probe`, and moved the task directory to `quarantine/anim-probe`. The original path was gone.

`bench flake --all` was not run. No seeded task was touched.

## Fix

The task was moved back out of quarantine and the `transition-delay` line was deleted, which disables the animation. The same scorer then returns 1 on the buggy tree and 0 on the golden tree. A second `flake_all` call with a fresh quarantine directory returned 0, left `anim-probe` in place, and printed nothing.
