## Where the code is, and one change from the brief

The redactor is `packages/argus-core/src/argus_core/redact.py`. `packages/guard/src/guard/redact.py` re-exports it. The brief asked for the code in `guard`, but `guard` depends on `fix-loop` and `argus-core`, so `argus_core.types` and `argus_core.telemetry` cannot import `guard` without a dependency cycle. The scan script also loads the same file by path, so it uses the same token shapes.

Wiring (two places, no change to `fix-loop`, `eval` or `repro-agent`):

- `argus_core.types.Trajectory.to_jsonl` masks the text it returns. Every trajectory file goes through it: `fix_loop.loop._write`, `repro_agent.loop`, the eval replays.
- `argus_core.telemetry.RedactingExporter` masks every string attribute, event attribute (the SDK's recorded exception text) and status text before a span reaches any exporter. `start_tracing` wraps both the default exporter and a test exporter.

## Findings

- `flow.agent_job.scrub` does **not** mask an installation token of the shape `ghs_<APPID>_<JWT>`. Run on a made-up `ghs_123456_FAKE...` value, `scrub` returned it unchanged; `redact` masked it. This confirms the guess in threat model section 9. `scrub` was not changed because `flow` is outside this task; moving it onto `argus_core.redact.redact` is a small follow-up for the owner (or for P7-T04, which introduces that token).
- `check_no_secrets.py` was **already failing** before this task: `golden.yml` names `secrets.PLATFORM_REPO_TOKEN`, which the old `MARKERS` check rejects. Nothing ran the script, so nobody saw it. `golden.yml` is now in `ALLOWED` for `secrets.` (read-only platform checkout, manual dispatch only).
- The new tracked-file scan found 7 made-up values in older tests and one stored trajectory (`Bearer secretKey` quoted from the code under test). They are listed by their text in `ALLOWED_MATCHES`, not by path, so a real token added to the same file still fails.
- The scan never prints a value: it prints `path:line: <first 4 characters>...`.
- A line that contains `FAKE` is skipped by the scan. Every fake value in the new tests contains `FAKE` or is built at run time.

## Not covered

- A success `output` (the patch) and the `argus-result` artifact are not redacted; the trajectory inside it is.
- Env values shorter than six characters, and secrets of an unknown shape in a variable whose name has no `KEY`, `TOKEN`, `SECRET`, `PASSWORD` or `CREDENTIAL`, are not masked.
- The remote URL check covers `http://` and `https://` remotes in the repository's git config and a user or token before the host in http or https URLs in tracked files. A token passed on a command line, or in an `ssh://` URL, is not checked.
- The scopes of the three GitHub tokens on GitHub were not checked (the inventory says so).
