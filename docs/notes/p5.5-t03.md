## How the operator is derived

`meta.json` of a mutant records the archetype but not the operator (`argus_bench.mutate._write`), and seeded tasks record neither. So `skills.split.pairs` reads `bug.patch`, hunk by hunk:

1. a hunk that adds no text is a deleted rule: `delete-rule`;
2. otherwise the CSS declarations that differ between the removed and added lines name it: `z-index`, `overflow*` (`overflow`), `flex-direction` (`swap-flex-direction`), or a `px` value on both sides (`change-unit`);
3. a hunk it cannot read (for example the selector edit `.glabel` -> `div.glabel` in seeded `wrong-element`) counts as every operator of the task's archetype (`drop-prop` and `change-element` for `wrong-element`), the bugsmith `OPERATOR_ARCHETYPE` mapping in `docs/bug-archetypes.md`.

The property is read per hunk, so a hard seeded task that touches two files gets a pair for each file. Check: for all 300 mutants the derived operator equals the one the generator implies for the recorded archetype (`missing-style` -> `delete-rule`, `font-size` -> `change-unit`); a test asserts it.

Known ceiling: a pure deletion of one declaration would read as `delete-rule`. That over-claims a pair, which is the safe direction for an overlap check.

## Train selection rule (fixed, no randomness)

For each archetype, 20 mutants; source files take turns (so the rare files are all in), and inside a file the picks are evenly spaced by id. Result by file: `ops.css` 35, `desk.css` 3, `assistant.css` 2. Final order: tier first (easy, medium, hard), then the archetypes interleaved, so any prefix is balanced. The order is the order T04 runs them in.

## Gaps to know about (nothing was weakened)

- **Mutants cover 2 of the 6 archetypes and one tier.** All 300 are `font-size` (111) or `missing-style` (189) and all have `tier: easy`; there are no medium or hard mutants. Balance across archetypes and tiers is therefore only between those two. Held-out covers all six archetypes and all three tiers. A skill learned on train can help `font-size` and `missing-style` held-out bugs; for `flex-direction`, `overflow`, `z-index` and `wrong-element` held-out bugs, an ablation gain is not expected from these skills. T08 should report per archetype.
- **Same file, different operator.** 35 of 40 train tasks edit `apps/canvas/src/ops/ops.css`, and 6 held-out tasks (`seed-e02`, `seed-m02`, `seed-h02`, `seed-h04`, `seed-h08`, `seed-h10`) also touch it, with `swap-flex-direction` or `z-index`. The mutants use `change-unit` or `delete-rule` on it. That passes the stated rule (no shared pair) but the train agent will read the same stylesheet. A file-only rule would leave 5 train candidates; that is the cost of the strict (file, operator) rule being the one asked for, and it was not adopted.
