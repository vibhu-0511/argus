# P6 architecture

Source: `phases/P06-argus-flow.md`. P6 runs the ticket-to-fix pipeline as a durable workflow (DBOS), reached by a webhook that is only a hint, repaired by a reconciliation poller, executed on GitHub Actions, with a human QA signal wait. Deployed on Render free with Neon free Postgres. This file grows by one section per task. After each wave the orchestrating session folds the sections into the diagram in `overview.md`.

P6 was started before P5.5 and before P5 finished, on the owner's choice; see `docs/notes/p6-waves.md`.
