# P7 architecture

Source: `phases/P07-argus-guard.md`. P7 writes the threat model for the pipeline, hardens it (secrets, token scope, egress, audit log), red-teams it with promptfoo, and measures three sandbox tiers (Docker, gVisor, Firecracker) on cold start and escape-test pass rate. This file grows by one section per task. After each wave the orchestrating session folds the sections into the diagram in `overview.md`.

P7 was started with P6 still open (draft PR) and with the dependency `P7-T00` on `P6-T25` waived; see `docs/notes/p7-waves.md`.
