## P5-T04 Eval runner and results JSON

New components:

- `eval.runner`: `run_eval(tasks, agent, config)` runs an agent callable (`Task -> Outcome`) over a task list, times each task, and returns a `Results`. `AgentConfig` names the agent factory (`module:function`).
- `eval.results`: the results JSON models and their JSON Schema. This is the contract that the report (T05), gate (T16), multimodal run (T19, T20) and dashboard (T21) read.
- `eval.stats`: `wilson` (95% interval, z = 1.96) and `percentile` (linear interpolation).
- `eval.stub`: stub agent with no model call, for tests and dry runs.
- `python -m eval run` and `python -m eval schema`: write one results JSON; print the schema.

Links to existing components:

- `eval.runner` -> `argus_core.types.Task` (the task list) and `eval.metrics` (fills `trajectory_metrics` from the rows that give a trajectory path)
- `eval.stats.wilson` -> same formula as `fix_loop.baseline._wilson` (test reproduces the P3 cell 20/29 = [0.507695, 0.827246])
- results JSON -> report (T05), gate (T16), dashboard (T21): read only
- `$_equivalent` -> price table (T11): stays `null` here; no dependency on it

Files: `packages/eval/src/eval/{stats,results,runner,stub,__main__}.py`, `packages/eval/schemas/results.schema.json`, `packages/eval/schemas/results.example.json`, `packages/eval/README.md` (field table and rules), `packages/eval/tests/test_runner.py`.

## P5-T11 Price table and dollar equivalent

New components:
- `prices.json` - per model input, output and cached-input price per 1M tokens, with a source URL and the date it was read.
- `dollar_equivalent(model, tokens_in, tokens_out, tokens_cached=0)` - tokens to list-price dollars. Cached tokens are part of `tokens_in`; they are billed at the cached rate and the rest at the input rate.

## P5-T05 Phase report

New components:
- `eval.report` - turns two results files into the Phase report table (Previous phase, This phase, Delta). Tokens/bug is in + out per task; $-equivalent is per task. A null or empty value is a dash, and a delta needs both sides.
- `python -m eval report [previous.json] [this.json]` - none: empty template; one file: it is this phase; two: previous, this.

Links to existing components:
- `eval.report` -> `eval.results.Results` (reads the results JSON only)
- `eval.runner` -> `argus_core.prices.dollar_equivalent` (T11, results half): fills `$_equivalent` from the summed scored tokens and the agent's `model`. No tokens gives `null`; tokens on a model with no price row raise `UnknownModelPrice`, never a silent 0.

Files: `packages/eval/src/eval/report.py`, `packages/eval/src/eval/runner.py`, `packages/eval/src/eval/__main__.py` (one subcommand), `packages/eval/tests/test_report.py`, `packages/eval/tests/test_runner.py`.

## P5-T16 Regression gate

New components:

- `eval.gate`: `compare(run, baseline, config)` returns a verdict with one line per check; `gate_main` is the CLI body. Resolve rate: the run's rate must be at or above the baseline's Wilson lower bound (minus a margin), so a drop that stays inside the baseline's interval is not a regression. Tokens per bug: `tokens_in + tokens_out` per scored task may grow only by a set fraction.
- `gate.toml`: the only place the thresholds live (interval `z`, `margin`, `max_growth`). `--config` points at another file of the same shape.
- `python -m eval gate <results.json> --baseline <baseline.json>`: prints the verdict; exit 0 pass, 1 regression, 2 input could not be read.
- `fixtures/gate/`: `baseline.json` (the real P3 variant A numbers, 20/29) and `worse.json` (made up, 12/29). Its README says which is which.

Links to existing components:

- `eval.gate` -> `eval.results.Results` (reads two results files) and `eval.stats.wilson` (baseline lower bound at the config's `z`)
- `python -m eval gate` -> `eval.__main__` (one subcommand registration)
- CI workflow (T17, later) -> `python -m eval gate`; ADR-017 (T18) sets the values in `gate.toml`

Files: `packages/eval/src/eval/gate.py`, `packages/eval/gate.toml`, `packages/eval/fixtures/gate/{baseline.json,worse.json,README.md}`, `packages/eval/tests/test_gate.py`.
