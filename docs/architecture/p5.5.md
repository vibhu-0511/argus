# P5.5 architecture

Source: `phases/P05.5-argus-skills.md`. P5.5 distils reusable skills from successful trajectories, loads them on demand (progressive disclosure), measures whether they help on held-out bugs, and shows that a poisoned skill cannot take over the agent. This file grows by one section per task. After each wave the orchestrating session folds the sections into the diagram in `overview.md`.
