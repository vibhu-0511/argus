{"name": "css-numeric-value-revert", "description": "Fixes a CSS property whose numeric value (border-radius, height, margin-top and similar) was changed from its original value, so the ticket says the property changed from some value. Use when a ticket reports a single style value on a class selector that no longer matches the design.", "body": "1. Read the ticket. Note the selector (for example `.ops-codes-card`), the property (for example `border-radius`), and the original value the ticket says it changed from.\n2. Use `search` on the selector across the app path. Keep only hits in `.css` files, or in style blocks, that declare a rule for that selector.\n3. Use `read_file` on the matching stylesheet around the hit. Find the rule whose selector matches the ticket exactly. Check the property's current value.\n4. If the current value differs from the original value in the ticket, that is the drift. If the property is set in more than one rule for the same selector, edit the rule the ticket names and leave the others alone.\n5. Use `edit` to replace only the value of that one property. Keep the rest of the rule and its selector unchanged. Use the exact old text from the file, including the selector, so the match is unique.\n6. Use `read_file` again on the edited rule to confirm the value now matches the original value in the ticket and the rest of the rule is unchanged.\n7. Use `submit`."}
